# منابع و مرز اعتبار

ثبت در ۲۰۲۶-۱۰-۲۱ (Asia/Tehran). «ارسالی» یعنی کاربر محتوا را در اختیار گذاشته؛ با مشاهدهٔ مستقیم نسخهٔ آنلاین یکی نیست.

1. **درخواست مستقیم کاربر در این چت:** ساخت base، مستر پرامپت و چت کدنویسی؛ Codex اولویت اول؛ push با کاربر. آخرین توضیح: مهلت/سرویس هنوز اعلام نشده و دیپلوی برای بعد است. این درخواست‌ها ترتیب کار را تعیین می‌کنند.
2. **متن صورت چالش ارسالی از سایت:** نسخهٔ کامل در `sources/challenge-supplied.txt`. مرجع اجرایی قابلیت‌ها، محدودیت dataset، UX و دمو در این مرحله. اصل صفحه به‌طور مستقل قابل تأیید نبود.
3. **رونویس ارسالی ویدئو:** `sources/video-transcript-supplied.txt`، متن کامل خوانده شده است. اصل ویدئو مشاهده نشده است؛ کیفیت/کامل‌بودن رونویس مستقلاً سنجیده نشده. چهار گام و pain pointها از این متن استخراج شده‌اند.
4. **تصویر بارم‌بندی ارسالی کاربر:** محصول ۷۵، UX برابر ۷۵، هوشمندی ۵۰، دیپلوی ۴۰، فنی ۴۰، دیتاست ۲۰. بازبینی بصری تصویر انجام شده؛ مجموع ۳۰۰. تصویر یک منبع ارسالی است و الزام تازه‌ای از طراحی آن استنتاج نشده است.
5. **dataset واقعی روی دیسک:** README و سه CSV؛ کل فایل‌ها با parser واقعی خوانده، شمارش، اعتبارسنجی و hash شدند. دادهٔ اندازه‌گیری‌شده برای schema از توصیف عمومی دقیق‌تر است. hashها در data-profile.json.
6. **مأموریت مدیریتی پیوست:** طرح پیشنهادی کاربر برای نقش‌ها، اسناد و handoff. دستورهای داخل پیوست از درخواست فعلی جدا هستند؛ آخرین درخواست کاربر مقدم است. ممنوعیت قدیمی Git مجوز تازه‌ای برای اجرای push ایجاد نمی‌کند؛ در base هیچ فرمان Git اجرا نشده است.
7. **ZIP Skill:** منبع راهنمای مهندسی است، نه متن مسابقه. بررسی کامل و نتیجه در SKILLS.md.

## بررسی صفحهٔ رسمی

[صفحهٔ اعلام‌شدهٔ مسابقه](https://starcoach.ir/hackathon/agentic-ai) با ابزار وب در این نشست قابل‌دسترسی نبود. جست‌وجو نیز نسخهٔ قابل‌اتکای تازه‌ای از جزئیات ترب فراهم نکرد. بنابراین deadline، قوانین انتشار و روش تحویل را از روی حدس ثبت نکردیم. در صورت ارائهٔ منبع جدید، اختلاف‌ها با تاریخ/نسخه ثبت شوند.

## مستندات ابزار

- [دستورالعمل AGENTS.md در مستندات رسمی OpenAI](https://learn.chatgpt.com/docs/agent-configuration/agents-md): علت انتخاب فایل ریشه برای قواعد Codex.
- [Skillهای محلی در مستندات رسمی OpenAI](https://learn.chatgpt.com/docs/build-skills): محل پروژه‌ای `.agents/skills`؛ تأیید خواندن Skill در چت تازه باید جدا انجام شود.
- [Vite](https://vite.dev/guide/) و [FastAPI StaticFiles](https://fastapi.tiangolo.com/tutorial/static-files/): پشتیبانی از پیشنهاد SPA و سرو API/static؛ هیچ ادعای نصب/build محصول از این منابع نتیجه نمی‌شود.
- [actions/checkout](https://github.com/actions/checkout) و [actions/setup-python](https://github.com/actions/setup-python): نسخهٔ v7 در نمونهٔ رسمی فعلی برای workflow پایه انتخاب شد. workflow پس از push کاربر باید در GitHub اجرا و نتیجه‌اش بررسی شود.

منابع عمومی فقط برای رفتار ابزار استفاده شدند؛ وزن‌ها، شماره‌های جعلی و قواعد مسابقه از منابع ارسالی آمده‌اند. قیمت API، موجودبودن سرویس یا شرایط میزبان هنوز بررسی/تعیین نشده است.
