## تصمیم و ارزش

استفادهٔ محدود و نصب محلی پروژه در `.agents/skills/competition-agent-engineer/` با محتوای اصلی بدون تغییر. از راهنمای rubric→شاهد، تفکیک تست deterministic و real-provider، حفظ uncertainty، بودجهٔ اجرای agent و handoff استفاده می‌شود. installation فقط کپی فایل‌های بررسی‌شده بود؛ هیچ دانلود وابستگی، تغییر تنظیم سراسری یا اجرای کد خارجی انجام نشد.

Codex طبق مستندات رسمی این مسیر را برای Skillهای محلی می‌خواند. در چت تازه فایل را صریح بخوانید و نامش را در handoff ذکر کنید؛ صرف وجود پوشه به معنی تأیید استفادهٔ runtime نیست. این نشست از متن Skill به‌عنوان راهنمای محدود استفاده کرده است.

## بخش‌های کنارگذاشته‌شده یا مشروط

- امتیازها، test countها، نسخه‌های مدل/SDK و مثال‌های مسابقه‌های قدیمی فقط سابقه‌اند؛ هیچ‌کدام معیار ترب یا مدرک کیفیت محصول ما نیستند.
- توصیهٔ inspection وضعیت Git با مرز کاربر تطبیق داده شد: برای base هیچ Git اجرا نشد؛ لازم نبود برای پیروی از Skill این مرز شکسته شود.
- پیشنهاد optional چندعامل/تفویض به کار نرفت؛ گردش‌کار کاربر ترتیبی و یک مالک است.
- توصیهٔ اثبات زودهنگام دیپلوی فعلاً با درخواست مستقیم کاربر به مرحلهٔ بعد منتقل شد؛ آن را مانع base یا علت سؤال تکراری قرار ندادیم.
- هیچ طراحی تیره، framework، provider، budget یا موعد اجباری در Skill یافت نشد. خطر اصلی تعمیم مثال‌های تاریخی به چالش فعلی است؛ AGENTS و قرارداد پروژه آن را محدود می‌کنند.
