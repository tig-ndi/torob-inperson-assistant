# تطبیق گزارش Figma با Base

## وضعیت بازبینی D42 | ۲۰۲۶-۱۰-۲۳

این بخش از وضعیت تاریخی Base در پایین جدیدتر است. نقشهٔ واقعی و خیابان‌های OSM با API/snapshot واقعی و بدون مدل بررسی شدند؛ خوانایی فیلتر تیره اصلاح شد. پنهان‌شدن sort/شواهد شرایط و کنترل نقشه در ارتفاع کم رفع شد؛ قطع عمدی کاشی و بازگشت به فهرست با حفظ انتخاب در سه اندازه رگرسیون دارد. تصاویر ۳۲۰/۳۹۰/۷۶۸ افقی/۱۴۴۰ در دو تم بدون overflow افقی بودند. این بررسی انتقال دقیق پیکسل‌های نقشهٔ نمونه یا پذیرش تمام F01–F18 نیست. دستگاه/کیبورد/صفحه‌خوان/زوم واقعی و پذیرش انسان هنوز بازند؛ ریشهٔ `/` دست نخورده است.

این شناسه‌ها متعلق به گزارش ارسالی Figma هستند؛ اثبات باگ در نسخهٔ فعلی یا ادعای انجام کامل همهٔ موارد نیستند. تصاویر گزارش و پروتوتایپ مرجع بصری‌اند؛ build/مشاهدات نویسندهٔ آن گزارش، اجرای این مرحله محسوب نمی‌شود.

- **F01:** مسئلهٔ دید اولیه در تصویر نمونه دیده می‌شود. Base اولویت فهرست کامل موبایل و پنل مشترک دارد؛ پذیرش نهایی اولین محصول/فروشگاه با A/B است.
- **F02:** پوستهٔ جدید قاب مصنوعی گوشی ندارد؛ عرض‌های نمونه و مرز 959/960 در تست Base هستند. صفحه‌های نهایی هنوز باید بررسی شوند.
- **F03:** CSS مبتنی بر dvh، پنجرهٔ کران‌دار و راه بدون drag آماده است. صفحه‌کلید واقعی iOS/Android و دوربین نقشه هنوز آزموده نیست.
- **F04:** adapterها و state/تاریخچه آماده‌اند؛ صفحهٔ نیازسنجی A و نقص backend شرطِ قبل از موضوع هنوز کار دارند.
- **F05:** نقشه/خوشه/پاساژ نمونه محدودیت قطعی دارند؛ پیاده‌سازی واقعی کار B است. Base فقط قرارداد و مجموعهٔ پین مشترک را دارد.
- **F06:** نقشهٔ جعلی منتقل نشده؛ جایگاه فعلی صریح است. GPS تنها با کلیک و انتخاب دستی آماده‌اند؛ provider و خط/محدوده با B.
- **F07:** انتخاب offer مستقل از رتبه در reducer و کارت پایه بررسی می‌شود؛ مقایسهٔ نهایی B باقی است.
- **F08:** هویت سه‌گانه، پاک‌سازی وابستگی‌ها با تغییر محصول و جدایی نتایج پیگیری آماده‌اند؛ تنوع قابل‌تأیید در API نداریم.
- **F09:** قیمت دقیق رشته/BigInt و جدایی summary/nearest حفظ شده‌اند؛ قیمت تازهٔ تأییدشده نداریم، سناریوی نمونه به واقعیت تبدیل نشده است.
- **F10:** متن‌های ساعت/قیمت/موجودی/اعتبار و آرایهٔ محدودیت شواهد در Base وجود دارند؛ تمام متن‌های صفحه‌های نهایی باید بازبینی شوند.
- **F11:** client و state پیگیری ارسال‌نشده آماده‌اند؛ UI پایدار پیگیری با B و فقط بر اساس قرارداد موجود است.
- **F12:** endpoint واقعی جایگزین و حفظ قیود وصل‌اند؛ نمایش empty/unknown و کنترل انتخاب با B است.
- **F13:** ناوبری مبدأ، مقایسهٔ مستقل از سفر و state مشترک آماده‌اند؛ scroll restoration و Back مرورگر برای صفحه‌های نهایی باقی‌اند.
- **F14:** Base موفقیت نمایشیِ clipboard/share/صوت ندارد؛ این قابلیت‌ها تا پیاده‌سازی واقعی نباید فعال‌نما شوند.
- **F15:** پنجرهٔ native با عنوان، Escape و بازگشت focus و کنترل‌های فرم آماده‌اند؛ تمام مسیرهای A/B بعداً آزمون keyboard می‌خواهند.
- **F16:** توکن‌های روشن/تیره مستقل و ترکیب‌های اصلی بازنگری شده‌اند؛ کنتراست همهٔ حالت‌های صفحه‌های نهایی هنوز اثبات نشده است.
- **F17:** مقایسهٔ محصول/آفر در A/B ساخته می‌شود؛ همهٔ انتخاب‌ها باید روی موبایل قابل دسترسی بمانند و overflow جدول محلی باشد.
- **F18:** reduced-motion پایه و قصد مستقل دوربین آماده‌اند؛ حرکت واقعی نقشه با B است. موشن تزئینی/کتابخانهٔ سنگین اضافه نشده است.

## تصمیم دربارهٔ مرجع‌های بیرونی

الگوی مفید مشترک: حفظ زمینه و انتخاب بین گفت‌وگو، کارت و نقشه؛ گرفتن state از ابزار معتبر، نه ساختن قیمت/مختصات توسط LLM.
نصب cloner یا مهاجرت به Next.js/OpenUI/CopilotKit برای این Base لازم نیست؛ پروژهٔ React/Vite و endpointهای فعلی حفظ می‌شوند. نقش این منابع الهام و بررسی الگوست، نه الزام به تعویض پشته یا واردکردن لوگو/تصویر/دادهٔ آن‌ها.
